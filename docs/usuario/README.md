## Papéis na prática

| Papel na plataforma | O que faz no dia a dia |
| :--- | :--- |
| Super Admin | Cadastra empresas, planos e módulos da plataforma |
| Admin da empresa | Utilizadores, funções, configurações e módulos ativos |
| Utilizador com permissões | Opera Processos, TeamOps, Produtos, Indicadores, RTD conforme a função |
| Solicitante (função básica) | Abre e acompanha solicitações no módulo Processos |
